## 組裝順序

1. 承重桿用定位銷對正，鎖到馬達輸出盤上。
2. 承重軸鎖入要用的孔位（P1–P5），法蘭貼平桿件。
3. 從下方穿 M12 螺桿：底面 **DIN 9021 大墊片** + 螺帽；頂端 DIN 433 小墊片 + 螺帽，鎖緊（扭矩待驗證，建議先 ≤ 8 N·m，避免壓壞 PETG）。
4. 套槓片 → 壓板（D 形孔對準切面）→ 星形旋鈕鎖緊 → 鎖緊旋鈕往下鎖、頂住旋鈕。

## 驗證（`cad/check_fit.py`）

組合件內零件兩兩無干涉；M12 夾緊路徑、槓片堆疊逐一接觸；壓板轉 2° 即撞到 D 切面（確實止轉）；
與兩顆馬達原廠 STEP 比對：只接觸會轉的輸出盤，與固定外殼至少保持 1.27 mm。
原廠 STEP 請放在 `cad/vendor/`（不納入版本控制）。
